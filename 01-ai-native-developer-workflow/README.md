# ai-dev-tools-zoomcamp — Homework 1

Use AI coding tools in real development workflows: prompting, agents, testing, code review, and shipping production-quality software faster.

This Django homework lives in `01-ai-native-developer-workflow/`. Run all project commands from that directory (the folder that contains `manage.py` and `pyproject.toml`).

## Setup

```bash
uv sync
uv run python manage.py migrate
uv run python manage.py createsuperuser
uv run python manage.py runserver
```

## Common commands

```bash
uv run python manage.py check
uv run python manage.py test chores
uv run python manage.py runserver
```
